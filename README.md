# NovaMart AI Retail Intelligence Platform — Capstone Project

An end-to-end retail analytics platform built on the Olist Brazilian E-Commerce dataset:
data engineering, EDA, customer segmentation, sales forecasting, delivery-delay and
satisfaction prediction, a recommendation engine, model explainability, and a deployed
Streamlit dashboard.

## Structure
- `notebooks/` — 9 analysis notebooks (00–08)
- `report/` — full capstone report
- `presentation/` — final presentation deck + presenter notes
- `dashboard/` — deployable Streamlit dashboard (see its own README to run it)
